System Architecture

Classify, Ground, Verify

The strict gate requires nonempty claims, every claim passing, no atypical action-critical claim, and no mechanism warning.

Ablation Study

Faithfulness Gradient

Mean structured-claim faithfulness across 100 saved responses per condition. Strict replay releases 85% sample-grounded, 48% values-only, and 17% class-only.

Sample + Class Grounding
96%
Both sample feature directions and class-level training priors included in the prompt. Full grounding condition.
Values-Only Grounding
63%
Prompt shows raw feature values but omits directional labels. LLM must infer directions — more error-prone.
Class-Only Grounding
33.77%
Prompt omits sample values entirely. LLM generates plausible-sounding but mostly ungrounded directional claims.

Monotonic faithfulness: SG (96%) > VO (63%) > CO (33.77%) in the saved experiment. Historical releases were 90%, 48%, and 17%. Strict replay is a re-evaluation of saved claims.

Known Limitations

Research Scope

Honest scope and failure modes.

Controlled Lab Data Only

Trained and tested on the IITK single-piston compressor dataset. Recording-session independence and generalisation to other machinery remain unverified.

Offline Batch Inference

No real-time streaming pipeline. Each diagnosis is a one-shot inference on a fixed 3.125 s pre-extracted window.

Binary Gate Outcome

The verifier outputs RELEASE or ESCALATE — no partial-confidence score. Escalated reports receive no automated fallback explanation.

LLM Output Format Dependence

Strict response validation rejects malformed structured claims. Original raw response envelopes were not retained, limiting retrospective schema checks.
