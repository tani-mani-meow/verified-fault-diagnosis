System Architecture

Three-Certificate Trust Protocol

Each certificate independently validates one layer of the diagnosis chain before the report is released.

Stage 1
Feature Extraction
84 time, frequency & wavelet packet features from 3.125 s WAV at 16 kHz
Stage 2
Classification
XGBoost + StandardScaler, trained on IITK dataset, 95.56% accuracy
Certificate 1
Stage 3
Grounding Retrieval
Physical mechanism + per-class feature directions from knowledge base
Certificate 2
Stage 4
LLM Explanation
Grounded prompt → Llama 3.1 70B → structured JSON with directional claims
Stage 5–6
Verify & Gate
Claims checked against sensor data percentiles → RELEASE or ESCALATE
Certificate 3

Ablation Study

Faithfulness Gradient

Grounding context injected into the LLM prompt is the single biggest driver of verifiable explanations. Removing it collapses faithfulness from 96% to 44%.

Sample + Class Grounding
96%
Both sample feature directions and class-level training priors included in the prompt. Full grounding condition.
Values-Only Grounding
71%
Prompt shows raw feature values but omits directional labels. LLM must infer directions — more error-prone.
Class-Only Grounding
44%
Prompt omits sample values entirely. LLM generates plausible-sounding but mostly ungrounded directional claims.

Monotonic faithfulness: SG (96%) > VO (71%) > CO (44%). The gradient is preserved across all 7 fault classes, confirming that grounding quality — not LLM stochasticity — is the primary driver.

Known Limitations

What This System Does Not Do

Honest scope and failure modes.

Controlled Lab Data Only

Trained and tested on the IITK single-piston compressor dataset. Generalisation to other machinery or noisy factory environments is unverified.

Offline Batch Inference

No real-time streaming pipeline. Each diagnosis is a one-shot inference on a fixed 3.125 s pre-extracted window.

Binary Gate Outcome

The verifier outputs RELEASE or ESCALATE — no partial-confidence score. Escalated reports receive no automated fallback explanation.

LLM Output Format Dependence

Claim extraction requires valid structured JSON. Malformed LLM responses are treated as zero claims and escalated automatically (4 of 100 audit cases).
