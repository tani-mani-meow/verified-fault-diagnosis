# Compressor Predictive Maintenance (compressor-pdm)

This project contains code for acoustic fault classification of a reciprocating air compressor using the IIT Kanpur Air Compressor Acoustic Dataset.

## Repo Structure
- `data/`: (gitignored) contains the dataset
- `src/download_data.py`: download and unzip the dataset
- `src/inspect_data.py`: inspect the dataset, generate reports and plots
- `outputs/`: contains plots and reports
- `scripts/verify.py`: validation script
